Fungsi ini memungkinkan SIPU mem-backup JSON utuh dari aplikasi ke Spreadsheets. ```javascript:Backend:Code.gs function doGet(e) { return ContentService.createTextOutput("API SIPU Aktif dan Siap Digunakan.") .setMimeType(ContentService.MimeType.TEXT); } function doPost(e) { try { const action = e.parameter.action; const data = e.parameter.data; if (action === 'backup') { const sheet = getSpreadsheet().getSheetByName(CONFIG.SHEETS.BACKUP); if(!sheet) return errorResponse("Sheet Backup tidak ditemukan"); // Simpan backup JSON lengkap berserta Timestamp sheet.appendRow([new Date(), data]); return successResponse("Backup berhasil disimpan ke Cloud."); } return errorResponse("Perintah tidak dikenali."); } catch(error) { return errorResponse(error.toString()); } } function successResponse(msg) { return ContentService.createTextOutput(JSON.stringify({success: true, message: msg})) .setMimeType(ContentService.MimeType.JSON); } function errorResponse(msg) { return ContentService.createTextOutput(JSON.stringify({success: false, message: msg})) .setMimeType(ContentService.MimeType.JSON); } ``` ### 3. File Konfigurasi Apps Script (`Config.gs`) Salin ini ke file `Config.gs`. **Penting:** Pastikan di Spreadsheet Anda, Anda telah membuat Sheet (Tab di bawah) bernama **"BackupData"**. ```javascript:Backend:Config.gs // Config.gs const CONFIG = { // MASUKKAN ID SPREADSHEET ANDA DI SINI SPREADSHEET_ID: 'MASUKKAN_ID_SPREADSHEET_ANDA_DI_SINI', SHEETS: { BACKUP: 'BackupData' // Buat tab sheet dengan nama BackupData } }; function getSpreadsheet() { return SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID); } ``` **Ringkasan Pembaruan yang Telah Dilakukan:** 1. **Tidak Ada Data Dummy:** Saat Anda log-in (`admin` / `admin`), data murni kosong dan siap untuk diinput. 2. **Kop Surat Dinamis 4-5 Baris:** Sudah terpasang aturan jika baris 4 dan 5 kosong, maka struktur HTML tidak akan menggambar elemen tersebut, dan tinggi (height) menyesuaikan secara otomatis. Terdapat 2 *upload input* untuk logo Kiri dan Kanan. 3. **Cetak F4 (10 Kartu per Lembar):** Menggunakan ukuran 215,9 mm × 330,2 mm dengan *layout* matriks 2x5. 4. **Pembagian Ruang 3 Mode:** Telah ditambahkan pilihan mode, integrasi drag & drop, otomatis hitung kebutuhan ruang, dan urutan gabung ruang acak. 5. **Integrasi Script Cloud:** Tombol sinkronisasi disertakan di menu kiri bawah. Mode operasional harian berjalan 100% *Offline* (sesuai janji SIPU pada poster penawaran Anda). Saat koneksi tersedia, cukup klik "Sync Ke Cloud".
